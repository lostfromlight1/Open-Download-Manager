# Security policy

## Reporting a vulnerability

Report security issues privately. Do not open a public issue that includes
exploit details.

Use GitHub private vulnerability reporting on this repository when it is
enabled. Until then, contact the maintainers directly. A security email address
is not published yet.

Do not include live download URLs, cookies, authorization headers, tokens, or
personal files in a report.

## Scope

This policy covers the desktop shell and, as they land, the download engine,
persistence, and browser integration.

Product security requirements are documented in [`docs/SECURITY.md`](docs/SECURITY.md).

## Disclosure

Give the maintainers time to confirm and fix an issue before publishing details.
